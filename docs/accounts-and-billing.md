# 员工账号与使用费用管理

## 本地使用

- Node.js 22.13+（本地数据库使用 Node 内置 SQLite）。安装依赖后执行 `npm run account:create` 创建首个管理员。
- 初始密码随机生成，保存在被 Git 忽略的 `.local-data/admin-login-时间.txt`；终端不输出密码。重复执行不会覆盖管理员。
- 登录页支持填写姓名、用户名、密码申请注册（密码 8–128 位），注册成功不创建登录会话。新申请固定为普通员工、待审批状态，不能使用平台 API。
- 管理员打开 `/admin` →“员工账号”批准或拒绝申请，也可直接创建账号、停用员工或重置密码。审批状态与启用状态分别校验，不能用“启用”绕过审批。密码只保存加盐哈希。
- 员工列表支持最多 500 字管理员备注，可编辑或清空，仅管理员接口返回，不修改注册姓名/用户名，不在登录和个人资料接口中公开。
- 首次启动会以兼容方式增加审批状态和备注字段。已有账号默认已批准，原有停用状态不变。注册接口校验请求来源、限制请求体大小，并按 IP 的哈希每小时限制 10 次有效格式注册尝试（不保存原始 IP）。
- 账号系统替代旧认证码；所有平台 API 都要求有效服务器会话。普通员工不能访问管理接口，不能查询他人生成任务或归档图片。
- 本地数据库保存在 `.local-data`，备份时一起备份。不要提交到 Git。新生成图片不归档到服务器、数据库或 Blob。

## 账单与内容

- 共享原来的服务端 API 密钥，每次上游 POST（包括重试）各记录一条调用和唯一 UA；供应商返回的请求编号一起保存。
- 管理员可查看员工、实际请求模型、功能、提示词摘要（最多 1000 字符）、请求结果及费用。不保存图片本体；历史归档仅保留读取兼容。摘要可能含文档片段，因此仅授权管理员可访问。
- 在“账单对账”导入 65535 原始 CSV：先预览，再确认。费用以供应商 `cost_usd` 原值保存（9 位小数精度），不擅自换算人民币。
- 只用请求编号或唯一 UA 精确匹配，且检查模型一致。重复导入不重复计费；编号相同且已知费用或身份字段冲突则整批拒绝。未知来源和上线前历史记录保留为待核对，不自动分配员工。
- 空白 cost_usd 保存为 NULL（费用未提供），不当作 0 元、不计入已对账数量，也不阻止其他记录导入。无效的非空金额仍拒绝，并显示 CSV 记录序号。后续相同请求、模型、时间和 UA 的账单可补齐空白费用及状态；重新导入旧的空白账单不会覆盖已知金额。
- 供应商重试沿用请求编号时，相同模型和 UA 下，较早的 4xx/5xx 空费用记录与较晚的 2xx 已知费用记录合并，保留成功记录的时间、状态和费用。同份 CSV 的顺序不影响结果，跨次导入也可补齐；旧失败记录不会覆盖成功记录。两笔已知金额不同或身份冲突仍整批拒绝。
- 未导入的调用显示“未导入对应账单”，已匹配但空白费用显示“费用未提供”。失败/超时调用仍保留，是否收费以 CSV 为准。首次连接会兼容迁移费用列为可空，已有费用与关联保持不变。
- 请求日志不保存 CSV 的 API 密钥/IP 列。CSV 本身建议管理员安全保存，不上传代码仓库。
- 已验证 65535 文本请求的响应编号与导出 CSV 编号、UA 一致；其他模型通道需以实际账单继续确认，无法匹配的记录不会自动记到员工名下。
- 异步任务需前端查询到完成后更新状态；关闭页面导致尚未查询完成的任务可能保留生成中，重新打开恢复查询后更新。
- 个人聊天与画廊仍存当前浏览器，并按登录账号隔离；服务器只保存管理台账。不跨设备同步图片，清理浏览器数据可能丢失图片，请下载重要成果。旧浏览器历史不自动划给新员工，不会删除原始历史。
- 所有登录用户（管理员和员工）均可在平台“我的账号”点击“导入此浏览器的旧历史”，将当前浏览器、当前网址下上线前的策划、导图、自由对话和画廊复制到当前账号；同编号记录不会覆盖，原记录保留。共用电脑需确认旧记录属于本人，不会读取其他已登录账号的独立历史。复制后刷新页面。管理后台入口和管理接口仍仅对管理员开放。

## Vercel 部署

上线前必须完成配置，否则本地可用不代表云端可用：

1. 为该项目连接 PostgreSQL，服务端设置 `DATABASE_URL`（使用服务提供商的带 TLS 连接串，推荐连接池地址）。首次连接自动建表；生产部署前应备份数据。
2. 不需要创建图片归档存储。视频参考图已有的 Public Blob 及 `BLOB_READ_WRITE_TOKEN` 保持不变，它与管理后台的数据存储是两回事。
3. 可设置 `PINWU_APP_ORIGIN=https://你的正式域名`；必须与访问域名一致。预览部署不要复用生产域名设置。
4. 保留当前服务端模型密钥（`PERDESIGN_*`）。密钥不发送给浏览器。数据库和 Blob 令牌也不得使用 `NEXT_PUBLIC_` 前缀。
5. 使用连接到生产数据库的受信任本地环境执行一次 `npm run account:create`，创建生产管理员。不要把本地 SQLite 数据直接复制到 Vercel。
6. 重新部署后，验证：未登录 API 返回 401；普通员工访问管理接口返回 403；经授权实际生成一次并导入账单，核实员工、模型和费用。

Vercel 无数据库时会明确拒绝账号服务，不回退到临时文件系统。生产数据库与本地 SQLite 独立，不自动迁移本地账号或历史记录。数据库应单独备份并限制访问。

当前云数据库选择 Neon 免费套餐，不开通付费升级。免费额度并非无限，应定期查看数据库用量；程序不自动删除账单历史。模型调用及现有视频 Blob 的费用不包含在数据库免费额度里。
